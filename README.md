# Анализ успеваемости учащихся

Кроссплатформенное приложение с графическим интерфейсом для автоматизированного анализа успеваемости школьников на основе HTML-файлов, экспортированных из системы "Дневник.ру".

## 📋 Описание проекта

Проект представляет собой систему анализа успеваемости, разработанную для образовательных учреждений. Приложение позволяет автоматизировать процесс обработки данных из электронных журналов, экспортированных из платформы "Дневник.ру", и предоставляет детализированную аналитику по различным категориям учащихся.

**Ключевые возможности:**
- Автоматический парсинг HTML-файлов формата "Дневник.ру"
- Интеллектуальная категоризация учащихся по 6 критериям успеваемости
- Многоуровневая визуализация данных (школа → параллель → класс)
- Генерация структурированных Excel-отчетов
- Кроссплатформенная поддержка (RedOS, Windows)

**Для кого предназначен проект:**
- Классные руководители
- Администрация учебных заведений
- Методические службы
- Службы контроля качества образования

## 🛠 Технологический стек

### Основные технологии
- **Язык программирования**: C++20
- **Фреймворк GUI**: Qt6 (Core, Widgets, Xml)
- **Система сборки**: CMake ≥ 3.16 с генератором Ninja
- **Тестирование**: Doctest 2.4.0+
- **Документирование**: Doxygen

### Библиотеки и модули
- **Парсинг HTML**: QtXml (QDomDocument)
- **Регулярные выражения**: QRegularExpression
- **Локализация**: QLocale (обработка чисел с запятыми)
- **Работа с файлами**: std::filesystem, QFile
- **Генерация отчетов**: QtXlsxWriter
- **Обработка ошибок**: Механизм исключений C++

### Архитектурные паттерны
- **Основной паттерн**: MVC (Model-View-Controller)
- **Паттерны проектирования GoF**:
  - Observer (наблюдатель) для обновления UI
  - Factory Method для создания парсеров
  - Strategy для алгоритмов анализа
- **Архитектурные слои**:
  - Parsing Layer (парсинг данных)
  - Model Layer (бизнес-логика)
  - Controller Layer (координация)
  - View Layer (пользовательский интерфейс)

### Тестирование
- **Модульное тестирование**: Doctest
- **Интеграционное тестирование**: Тесты полного цикла обработки
- **Тесты производительности**: Проверка временных ограничений
- **Покрытие кода**: Цель ≥ 80%

## 🚀 Сборка и запуск

### RedOS 7.x

```bash
# Установка зависимостей
sudo dnf install qt6-qtbase-devel qt6-qttools-devel cmake ninja-build gcc-c++ doctest-devel

# Клонирование проекта
git clone <репозиторий>
cd AnalyticsApp

# Сборка QtXlsxWriter (если не установлен)
git clone https://github.com/dbzhang800/QtXlsxWriter.git
cd QtXlsxWriter
mkdir build && cd build
cmake -G Ninja -DCMAKE_BUILD_TYPE=Release ..
ninja
sudo ninja install
cd ../..

# Сборка основного проекта
mkdir build && cd build
cmake -G Ninja -DCMAKE_PREFIX_PATH=/usr/lib64/qt6 -DCMAKE_BUILD_TYPE=Release ..
ninja

# Запуск тестов
./tests

# Запуск приложения
./AnalyticsApp
```

### Windows 10/11

```bat
# Требуется: Visual Studio 2022, Qt6, CMake
mkdir build
cd build
cmake -G "Visual Studio 17 2022" -A x64 -DCMAKE_PREFIX_PATH="C:/Qt/6.x.x/msvc2019_64" ..
cmake --build . --config Release

# Запуск
AnalyticsApp.exe
```

## 📊 Основные функции

1. **Чтение данных**: Рекурсивный обход директории с HTML-файлами формата "Дневник.ру"
2. **Парсинг**: Извлечение ФИО, предметов и средних баллов
3. **Анализ**: Категоризация учащихся по 6 критериям
4. **Визуализация**:
   - Статистика по школе
   - Анализ по параллелям с процентами
   - Детализация по классам
5. **Отчётность**: Генерация report.xlsx с 10 вкладками по параллелям

## 📄 Формат входных данных

Приложение работает с HTML-файлами, экспортированными из "Дневник.ру":
- Файлы с расширением `.xls` (фактически HTML, MIME-type: text/html)
- Формат баллов: целые числа 0-5000 (5000 = 5.0)
- Структура: заголовок класса, таблица с ФИО и предметами
- Особенности: сокращенные названия предметов, служебные строки
